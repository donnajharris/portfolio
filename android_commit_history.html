Dine Around Commit History

These screenshots show the GitHub commit history for selected Dine Around project files. The repository is private, so the screenshots offer a record of changes made during development. Each file group begins with a short summary of the changes visible in its history.

PlacesListAdapter.java

The screenshots show commits for place cards, favourites, ratings, filters, empty-list messages, and open or closing status. They also show later refinements to the adapter as the app was integrated.

place_item.xml

The screenshots show changes to the place card layout, including labels, rating states, favourite placement, and adjustments for different languages.

strings.xml (French)

The screenshots show changes to the French strings, including place labels, feedback messages, and layout-related wording.

TimeHelper.java

The screenshot shows commits for time and date handling, cleanup, and a fix to date and time translation.

TimeHelperUnitTests.java

The screenshots show the test file history, including its move into the util package and commits made while the time helper was developed.

PlaceDayHourHelper.java

The screenshots show work on opening hours, closing-soon and open-now indicators, happy-hour handling, and refactoring of the helper.

PlaceDayHourHelperUnitTests.java

The screenshots show unit tests for missing opening hours and other helper methods, along with refactoring to make the code easier to test.

PlaceDayHourIntegrationTests.java

The screenshots show the integration test file history, including tests added for the day-and-hour helper and its later move into the util package.
